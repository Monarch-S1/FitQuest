## 🚀 NEXUS Quick Commands

| Mode | Command |
|------|---------|
| Full pipeline | `Activate Agents Orchestrator in NEXUS-Full mode for [project].` |
| Sprint | `Activate Agents Orchestrator in NEXUS-Sprint mode for [feature].` |
| Micro task | `Activate [Agent] to [do specific task], then verify with Evidence Collector.` |
| Code review | `Use the Reality Checker agent to audit this code for production readiness.` |
| Mobile audit | `Use the Mobile App Builder agent to review this React Native implementation.` |
| QA pass | `Use the Evidence Collector agent to verify this feature with visual proof.` |
