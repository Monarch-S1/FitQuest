# ARCH Logo Generation Prompts

Use these prompts in Midjourney, DALL-E, or Flux to generate your app logo.

---

## 🎯 Primary Logo (Icon — App Store)

### Midjourney Prompt
```
Minimalist geometric fitness app logo, abstract human figure in 
calisthenics pose performing a muscle-up, angular and sharp design, 
dark charcoal background #0F1115, bold amber gold accent #F59E0B, 
clean vector flat style, no text, square format 1:1, Android adaptive 
icon compatible, professional app store quality, inspired by Nike 
Training Club and Freeletics --ar 1:1 --style raw --s 250
```

### DALL-E / GPT-4o Prompt
```
Create a minimalist app icon for a calisthenics training app called 
"ARCH". The design should be:
- A geometric, angular silhouette of a person performing a muscle-up 
  or pull-up on a bar
- Dark background color: #0F1115 (near-black)
- Primary accent color: #F59E0B (amber/gold) for the figure
- Clean, flat vector style with no text
- Modern, premium feel like Nike Training Club or Freeletics
- Square format suitable for Android adaptive icon
- Sharp edges, not rounded — the brand is tactical and precise
```

### Flux Prompt
```
App icon for calisthenics fitness app, minimalist geometric human 
figure doing a muscle-up, angular sharp design, dark background 
#0F1115, amber gold figure #F59E0B, flat vector style, no text, 
square format, professional app store quality, modern premium design
```

## 🏷️ Full Logo (Wordmark + Icon)

### DALL-E Prompt
```
Create a logo for "ARCH" calisthenics training app:
- Icon: Geometric angular figure in muscle-up pose (amber #F59E0B)
- Wordmark: "ARCH" in bold condensed sans-serif font (like Bebas Neue)
  in white #F3F4F6
- Dark background #0F1115
- The icon sits above or to the left of the wordmark
- Clean, modern, tactical aesthetic
- No gradients, flat vector style
- Horizontal layout for web, stacked for app icon
```

## 🎨 Brand Specifications

| Element | Value |
|---------|-------|
| Primary Color | `#F59E0B` (Amber) |
| Background | `#0F1115` (Near-black) |
| Text Color | `#F3F4F6` (Off-white) |
| Font | Bebas Neue (headings), Inter (body) |
| Style | Geometric, angular, tactical, minimal |
| Avoid | Rounded shapes, gradients, busy details |
